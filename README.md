# Event Management System

Muhammad Qudama (23L-0852, BCS-7A)

A React app to browse events from the Ticketmaster Discovery API, see their details and register for them. Built with React, Redux Toolkit and React Router.

To run it, add your Ticketmaster API key to a `.env` file as `VITE_TM_API_KEY`, then run `npm install` and `npm run dev`.
